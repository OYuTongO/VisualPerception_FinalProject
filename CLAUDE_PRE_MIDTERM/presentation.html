技术选型依据

视觉MediaPipe Tasks API（0.10.35+）
模型RandomForest — 速度快，无需 GPU
界面Pygame — 跨平台，零依赖渲染
数据Kaggle ASL Alphabet（87,000 张）

关键设计决策

  • MediaPipe 0.10+ 移除了 mp.solutions API，改用 Tasks API + .task 模型文件
  • 坐标二次归一化到手部 Bounding Box，消除位置和尺度干扰
  • 排除 J、Z（动态手势），仅识别 24 个静态字母
  • 摄像头帧在子线程采集，Pygame 主循环保持 30FPS

Game Modes Design

三大游戏模式

📖
Learn Mode
学习模式
按单词逐字母引导练习，吉祥物实时反馈，无时间压力
  • Easy 词库随机取词（如 CAT / SUN）
  • 高亮当前目标字母 + ASL 参考图
  • 正确后自动推进，停留 1.5 秒
  • → 跳过 / ESC 返回菜单
⏱
Test Mode
测试模式
计时计分，5 个随机单词，检验学习成果
  • 每字母限时 10 秒，超时自动失误
  • 答对 +10 分，完整单词额外 +20
  • 结束后显示弱点字母统计
  • Top 5 本地排行榜持久化
🕹
Freeplay
自由模式
全屏摄像头背景，实时展示识别结果，适合演示
  • 左上角大字显示当前字母 + 置信度
  • 最近 5 个字母横向滚动历史
  • 手部骨架实时叠加显示
  • 右下角迷你吉祥物跟随状态
单词库设计：
Easy: HI BYE CAT DOG SUN Medium: HELLO WATER APPLE Hard: FRIEND SCHOOL PYTHON
全部排除 J、Z
UI Character Design

吉祥物小人 — 视觉反馈核心

IDLE
等待 / 无手势
CORRECT ✓
举手欢呼 · 绿色光晕
WRONG ✗
摊手摇头 · 红色效果

实现方式

  • 纯 Pygame 基本图形绘制（圆形 + 线条），无需图片资源
  • 三种姿态坐标各自定义，线性插值实现 0.3 秒过渡动画
  • 接口：mascot.set_state("IDLE"|"CORRECT"|"WRONG")

触发逻辑

  • 无手 / 等待 → IDLE（轻微呼吸动画）
  • 连续 3 帧一致且匹配目标字母 → CORRECT
  • 置信度达标但字母错误 → WRONG
