一、项目定位
----------------------------------------------------------------

目标：
  面向零基础健全人士的 ASL 手指拼写学习游戏。
  玩家通过摄像头比划 ASL 字母，与虚拟角色 Diana 完成一段
  预设对话，在游戏过程中自然习得 A-Y（排除 J/Z）共 24 个
  静态手型。

核心体验闭环：
  Diana 发送消息（语音 + 文字同步）
    → 玩家看到自己那侧的灰色字母槽
    → 在摄像头前比划每个字母
    → 正确：字母由灰变金
    → 错误：Diana 发送对应字母的手势"表情包"，玩家看示范后重试
    → 全部填满 → Diana 回复下一句 → 循环
    → 通关：弹出结算画面，退出游戏

字母范围：A B C D E F G H I K L M N O P Q R S T U V W X Y
（完全排除 J、Z；代码与脚本层面不出现这两个字母）

── M2 多手同时识别 🔲 ─────────────────────────────────────

目标：
  摄像头内同时出现多个手时，能分别框选并各自输出字母+置信度。
  游戏端接口升级为：
    gestures = recognizer.get_all_gestures()
    # 返回 List[dict]，每项含 letter, confidence, hand_index

实现思路：
  MediaPipe Hand Landmarker 本身支持 max_num_hands=2，
  在 recognizer.py 中扩展为对每只手分别推理即可。

优先级：中（期末演示时单手识别已够用，此项是加分项）


── M3 Diana TTS 语音 🔲 ──────────────────────────────────

库：edge-tts（pip install edge-tts）
目标：
  给定一段文本，异步生成音频文件，Pygame 播放。
  推荐声音：en-US-AriaNeural（女声，自然度高）

接口设计（新建 src/utils/tts.py）：
  speak_async(text: str, out_path: str) -> None
    # 调用 edge-tts，生成 mp3/wav 到 out_path
  # 游戏端在 Diana 开始"打字"时触发，音频与文字同步

注意：
  edge-tts 需要联网。若无网络，降级方案：pyttsx3（离线）。


── M4 语音与字幕同步 🔲 ──────────────────────────────────

目标：
  Diana 气泡中的文字以"打字机"速度逐字出现，
  速度与 TTS 音频的时长对齐。

实现方式：
  1. 提前统计音频时长（edge-tts 生成时记录）。
  2. 按 总字符数 / 音频时长 = 每秒字符速度 设置打字速度。
  3. Pygame 播放音频的同时，learn_mode 以对应速度推进
     typed_count。

降级：若时长不易获取，固定打字速度 28 字符/秒，视觉上已够用。
